## 1.0.20261015.180000 — Creation: bilingual documentation builder

Reason for the request:
  « If I put all these programs on GitHub as open source ... create documentation that an Odoo and Linux expert can use ... in web pages or a wiki on our website, so that the documentation is always up to date. »

Changes:
  - docs/en and docs/fr: 17 Markdown pages (overview, one page per program, rlq_survey_report, permissions, testing/translation).
  - docs/build_docs.py: inserts each program's real --help (per language) at the {{HELP}} placeholder; writes Markdown (docs/build/<lang>) and an Odoo 18 module rlq_tools_docs (website pages /docs/<lang>/<page>, redirect /docs/<lang>, language switch and page menu on every page).
  - Personal data still present in two help texts is masked by the builder (SCRUB) until the sources are cleaned.

Bugs fixed:
  - None.

Guards and edge cases:
  - The two languages must have exactly the same pages (build stops otherwise); the generated XML is parsed before writing; a {{HELP}} placeholder without a matching program stops the build.
  - Knowledge (Enterprise-only) is not required: plain website pages.

Checks performed:
  - tests/test_docs.py (parity, real help in the right language, valid XML, no personal data); module never installed in a real Odoo (NOT TESTED).

Action required from me:
  - Install rlq_tools_docs on a development Odoo first and check the pages render and the menu links work.
