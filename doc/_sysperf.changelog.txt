Reason:
  "[0] When registering for an event in Odoo, validate that people wrote a valid e-mail (example: mariebc33@gmail'com); add a menu option to list the e-mail errors caused by a wrong address, fix the user's contact and resend the e-mail. Changes:
  - snapshot(), rates(): processor (busy, user, system, iowait, steal), PSI cpu / io / memory (container cgroup v2 when it exists, else /proc/pressure;
    exact percentages from the cumulative "total" counters), whole disks of /proc/diskstats (% busy, operations, KB/s, wait per read / write, queue),
    memory, network (/proc/net/dev), ZFS ARC (hit ratio, size, maximum, throttle, L2ARC).
  - Helpers: cgroup_root, psi, diskstats, rotational, disk_model, busiest_disk, loadavg. No external command.

Bugs fixed:
  none.

Safeguards and edge cases:
  - Unreadable source: simply absent (container without PSI, no ZFS); partitions, loops, RAM disks, CD-ROM and network block devices ignored.
  - NGINX_TOOLS_PROC_ROOT prefixes every path (tests: fake /proc and /sys).
