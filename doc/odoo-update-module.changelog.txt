## 1.11.20261016.173838 — Quiet site before stopping Odoo, copy of the modules, check after the start, automatic rollback, Ctrl+C at once

Reason:
  wait up to 15 min for a quiet site; back up the modules; roll back to the previous versions after errors.

Changes:
  - New step « Attente d'un site calme »: active visitors = addresses with a request in the last 5 minutes in the nginx access logs
    (robots, tools and this server excluded; end of each file only); from --busy-visitors (BUSY_VISITORS, 3) the site is busy: new
    try every 30 s, at most --wait-quiet minutes (WAIT_QUIET, 15; 0 = no wait), then the update runs anyway (said).
  - New step « Copie des modules »: tar.gz of the module folders BEFORE anything changes (MODULES_BACKUP_DIR, /var/backups/odoo-update-module,
    mode 700, the last 10 kept, list of the folders next to it); impossible: nothing is stopped.
  - New step « Contrôle du journal d'Odoo depuis le démarrage »: ERROR / CRITICAL lines of the service journal (journalctl --since the start)
    and of Odoo's logfile (UTC times), after the warm-up (or 15 s without it).
  - Rollback (rollback()): after a failed update, a failed start or errors in the log, IF this run replaced the code (--zip): stop, module
    folders put back from the copy, update again (the database follows the previous code), start, warm-up, check. Question on a terminal
    (Enter = yes), automatic otherwise (cron, systemd); --no-rollback (ROLLBACK=non) to forbid it. Archive that failed to unpack: files
    restored before the restart.
  - Ctrl+C: the update runs through run_interruptible (apps/_i18n.sh 1.11): the question comes AT ONCE (it came only after up to --timeout
    seconds); yes: the update is stopped and the service restarted if it was active (interrupted_cleanup); odoo-backup.sh runs through
    ctrl_c_child (one question); warm-up: timeout --foreground.
  - Options (alphabetical): --busy-visitors N, --no-rollback, --wait-quiet MIN; keys BUSY_VISITORS, MODULES_BACKUP_DIR, ROLLBACK, WAIT_QUIET
    (doc/odoo-update-module.conf.example); lang/odoo-update-module.en.po.
